# 捡手机模拟器

把人物的聊天、照片与社交动态，制作成一部可以打开、翻阅的虚拟手机作品。

捡手机模拟器是一款面向「捡手机文学」的可视化创作工具。你可以为人物配置不同平台的账号，编排消息、动态、相簿、通话和备忘录，再通过手机界面呈现给读者。创作过程无需编写代码。

点击体验：https://thooog.github.io/phonefoundry/

## 从一个空项目，开始你的作品

你可以新建空项目，自行设定人物和内容；也可以载入「功能展示 · 从这里开始」，先体验各项功能。

示例使用中性的演示人物 A / B 和几何图片，不预设人物身份、人物关系或剧情。打开示例中的「备忘录 → 功能导览」，即可查看使用说明。载入示例会创建新项目，不会覆盖已有作品。

基本创作流程：

1. 创建人物，填写各平台账号资料。
2. 指定手机所属人，确定聊天中的我方身份。
3. 编排各个应用里的内容。
4. 调整壁纸、桌面和阅读设置。
5. 预览作品，导出后分享给读者。

## 人物与跨平台账号

一个人物可以拥有多种平台身份。你可以为不同平台分别填写昵称、用户名、简介和头像，让同一个人在不同应用中呈现不同的资料。

- **人物资料**：名称、简介与头像。
- **KakaoTalk**：昵称、Kakao ID、状态签名、头像与好友列表。
- **信息／电话**：显示名称、电话号码、邮箱、备注与头像。
- **Instagram**：昵称、用户名、简介、头像、粉丝数、关注数与关注列表。
- **X**：昵称、用户名、简介、头像、主页横幅、粉丝数、关注数与关注列表。

人物头像可以被平台账号继承，也可以为账号单独设置头像。信息与电话共用一份账号资料。

KakaoTalk 好友列表由创作者明确选择：在手机所属人的 KakaoTalk 账号中选为好友的人物，才会出现在作品的好友页。好友与会话参与者分别配置，创建会话不会自动建立好友关系。

## 在八个应用中编排内容

### 信息

以文字和图片构建短信式对话，配置发送者、消息时间与已读状态。

- 支持人物参与者，也支持直接填写名字或号码的自定义发送者。
- 图片消息支持单图或多图，每条最多 9 张，可调整图片顺序。
- 支持日期分隔和已读时间，手机所属人的消息显示在右侧。
- 可粘贴整段文本批量导入，并在写入前核对解析结果。
- 读者可搜索会话、打开图片并翻页查看。

### KakaoTalk

通过好友页、会话列表和聊天界面展示即时通信内容。

- 支持文字、图片、贴图、语音样式、系统消息，以及语音／视频通话记录。
- 可为语音填写时长和转写文字；读者可以展开或收起转写。
- 可设置通话类型、接通或未接状态与通话时长。
- 支持会话置顶、搜索、批量文本导入和图片查看。
- 好友页按照人物账号中保存的好友列表显示。

语音样式不播放真实音频，通话记录也不会发起真实通话。KakaoTalk 不提供信息应用中的已读回执配置。

### Instagram

用图片帖子、评论和故事呈现人物的社交内容。

- 支持单图、多图帖子及图片顺序调整。
- 可编写评论与嵌套回复，填写展示用互动数字。
- 可为人物编排多帧故事，设置文字和预设已看状态。
- 支持查看自己或其他人物的主页、帖子和关注列表。
- 可配置搜索记录，供读者继续浏览。

### X

编排文字动态、图片动态和回复线程。

- 支持多图帖子、嵌套回复，以及点赞、转发、回复和浏览数字。
- 可配置人物的点赞与转发标记，决定动态是否出现在首页。
- 可分别配置平台关注列表、趋势条目与搜索记录。
- 读者可以浏览主页、搜索帖子与人物、查看图片，并独立切换帖子的点赞和转发状态。

X 与 Instagram 的多图帖子均可继续添加图片，当前不设置固定的 4 张上限。主页填写的粉丝数、关注数用于展示，与实际选择的关系列表分别保存。

### 电话

配置通讯录与通话记录，呈现人物手机中的联系信息。

- 联系人可以关联已有的人物，也可以独立填写。
- 支持电话号码、邮箱与备注展示。
- 可编排呼入、呼出、未接记录和通话时长。
- 通话记录也可以直接填写陌生号码，无需先创建联系人。
- 提供联系人详情和拨号界面，相关交互用于作品展示，不会拨打真实电话。

### 照片

上传图片，整理人物的图库与相簿。

- 图库按拍摄日期分组，可填写图片说明和地点。
- 支持自定义相簿、收藏、已隐藏和最近删除状态。
- 可打开图片查看器，通过滑动或缩略图翻页。
- 已隐藏与最近删除相簿可分别配置阅读密码。

上传静态图片时会按入口进行缩放和压缩，GIF 保留原文件。建议在预览中检查图片清晰度与展示比例。

### 备忘录

使用单行或多行文字编排便签、清单和长文。

首个非空行作为标题，其余文字作为正文；列表会展示摘要和时间。读者可以搜索并打开全文。

### 设置

以模拟系统设置界面展示手机所属人及设备信息，并提供设置项搜索。作品中的设置界面用于阅读展示；创作者通过「作品设置」调整作品参数。

## 布置手机桌面

除了应用内容，你还可以调整手机的外观与桌面布局。

- 设置手机名称、所属人、壁纸和时间格式。
- 调整桌面应用与 Dock 中的图标位置。
- 添加装饰图标，以及日期、天气、便签和时钟小组件。
- 使用自定义 HTML 图标与小组件制作静态展示内容。
- 配置锁屏密码、相簿密码、手机外框与自动全屏选项。

装饰图标不提供对应应用的完整功能。HTML 图标和小组件只用于静态展示，不能执行脚本或作为可联网运行的独立应用。

## 预览、分享与继续创作

创作过程中可随时预览手机中的实际阅读效果。进入预览或导出前，网站会先保存当前改动；保存失败时会中止操作，避免使用旧内容。

导出时可选择四种方式：

| 导出选项       | 适合的用途               | 使用方式                                                     |
| -------------- | ------------------------ | ------------------------------------------------------------ |
| **作品包**     | 分享给读者               | 下载 ZIP，解压后打开其中的 `index.html`                      |
| **独立 HTML**  | 分享单个文件             | 下载 HTML 文件，使用浏览器直接打开，无需解压                 |
| **项目备份包** | 备份或迁移完整作品       | 在网站的项目列表中点击「导入备份」，恢复为可继续编辑的新项目 |
| **导出人物**   | 在其他作品中复用人物配置 | 导出全部人物、平台账号及相关图片，通过「导入备份」创建新项目 |

人物包保留人物头像、账号头像、横幅及相关配置，不包含聊天、帖子、相册等剧情内容。没有人物时，该选项不可用。

导入备份或人物包会创建新项目，不覆盖已有作品，也不合并到当前项目。给读者的作品包和独立 HTML 不能代替完整项目备份。

导出面板会提供体积预估。独立 HTML 将图片内联到文件中，通常会比压缩后的作品包更大。

## 读者如何体验

作品以「锁屏 → 桌面 → 应用 → 详情」的方式阅读。读者可以解锁手机、切换应用、翻阅对话、浏览动态、查看图片与故事，也可以使用已提供的搜索和阅读交互。

作品包和独立 HTML 可在支持的浏览器中离线打开。项目内的图片随作品导出；外部链接能否访问仍取决于网络与目标服务。手机上的文件打开方式和全屏权限也会受到系统、浏览器的限制，分享前建议用实际设备检查一次。

读者的点赞、转发、搜索或故事阅读状态不会写回创作者的项目，也不会向真实社交平台发送内容。

## 数据与使用须知

- **本地保存**：项目和上传资源保存在当前浏览器、当前站点的本地存储中，没有云端同步。不同浏览器、设备或站点地址之间不会自动共享项目。
- **定期备份**：清理浏览器数据、使用临时浏览模式或遇到存储异常，都可能影响数据保留。请定期导出项目备份包，换设备或换站点前尤其如此。
- **多标签页编辑**：同一项目通过编辑锁防止多个标签页互相覆盖，请按界面提示接管编辑或另存副本。
- **密码不加密**：锁屏与相簿密码只是作品交互，不加密文件，不构成隐私保护。不要填写真实密码或将敏感信息视为受保护内容。
- **当前功能范围**：暂不提供音乐、日历、YouTube 内容编辑，不支持帖子视频或视频消息。视频通话记录的展示不等于视频文件播放，部分模拟控件仅提供外观或按压反馈。
